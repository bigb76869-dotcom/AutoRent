## 🔑 Негізгі Бөлімдер (Main Pages)
- 🏠 **Басты Бет (`home2.html`):** Жүйе туралы жалпы ақпарат және артықшылықтар.
- 🚘 **Автопарк (`cars2.html`):** Көліктер тізімі, бағалары мен сипаттамалары.
- 👑 **Премиум Зал (`Премиум Автопарк.html`):** Элиталық көліктерге тапсырыс беру.
- ℹ️ **Біз туралы (`about2.html`):** Компания және авторлар туралы ақпарат.
